## 🎓 INTERVIEW PREPARATION

### Technical Depth Questions to Prepare For:

**1. Architecture & Design**
- Q: Why did you choose Spring Boot over other frameworks?
- A: Spring Boot reduces boilerplate, provides excellent security integration, and scales to enterprise needs. Perfect for mission-critical systems.

- Q: How did you structure your codebase?
- A: MVC pattern (Controllers → Services → Repositories). This separation ensures business logic is testable and independent.

**2. Database & Performance**
- Q: Why MongoDB instead of PostgreSQL?
- A: MongoDB's flexible schema handles varied emergency types. Geospatial queries enable efficient GPS-based searches. Cloud Atlas provides automatic scaling.

- Q: How did you optimize query performance?
- A: Implemented proper indexing on frequently queried fields, connection pooling for efficient database connections, and eliminated N+1 query problems through eager loading.

**3. Authentication & Security**
- Q: Walk us through your JWT implementation
- A: JWT eliminates session storage, enabling stateless authentication perfect for microservices. Tokens include role information, CORS/CSRF protections add layers of security.

- Q: How do you handle token expiration?
- A: 24-hour expiration (configurable). Refresh tokens can be implemented for longer-lived sessions while keeping access tokens short-lived.

**4. Real-Time Features**
- Q: How does your GPS-based hospital discovery work?
- A: MongoDB geospatial queries find hospitals within radius. Results sorted by distance. Caching for frequently accessed hospitals.

- Q: How would you scale volunteer task assignment globally?
- A: Implement job queue system (RabbitMQ), add caching layer (Redis), shard database by geography, use microservices for independent scaling.

**5. Scalability**
- Q: Your system currently handles 1000 RPS. What's your plan for 10,000 RPS?
- A: Add API gateway for load balancing, implement Redis caching, separate read/write database replicas, break into microservices, add message queues.
